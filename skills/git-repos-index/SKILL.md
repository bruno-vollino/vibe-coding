## Find all git repositories in the workspace 
1. create a steering file that lists all git repositories in the workspace so you don't have to search for git repos every time. You will need to traverse all subfolders 3 levels deep for that.
2. ask where to save the steering file. Default is the main directory in the workspace (name it workspace-repos.md).
